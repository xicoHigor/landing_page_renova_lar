# landing_page_renova_lar
# 🏡 RENOVA LAR HIGIENIZAÇÃO

**Mais limpeza, mais saúde, mais bem-estar!**

## 📌 Sobre o projeto

O site da **Renova Lar Higienização** foi desenvolvido para apresentar os serviços de higienização de estofados, fortalecer a presença digital da empresa e facilitar o contato com clientes por meio do WhatsApp.

A página possui um design moderno, responsivo e alinhado à identidade visual da marca, utilizando azul-marinho, verde-limão e branco.

## 🎯 Objetivos

- Apresentar a empresa e seus serviços.
- Facilitar a solicitação de orçamentos.
- Divulgar os serviços de higienização.
- Melhorar a experiência de navegação em celulares e computadores.
- Fortalecer a presença digital da empresa.

## 🧼 Serviços oferecidos

- **Higienização de sofás**
- **Higienização de colchões**
- **Higienização de tapetes**
- **Higienização automotiva**

## 📍 Área de atendimento

Atendemos **Pentecoste, Paracuru e região**.

## ✨ Funcionalidades

- Landing page com apresentação da empresa.
- Identidade visual personalizada.
- Ícones próprios em PNG para representar os serviços.
- Layout responsivo para dispositivos móveis e desktops.
- Botões de chamada para ação (CTA).
- Integração com WhatsApp para contato e solicitação de orçamento.
- Seções de serviços, diferenciais e contato.
- Área preparada para exibição de vídeos.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura das páginas.
- CSS3 — estilos, identidade visual e responsividade.
- JavaScript — funcionalidades complementares.
- PNG — imagens e ícones dos serviços.
- WhatsApp — canal de contato com clientes.

*Observação: os nomes dos arquivos devem corresponder aos arquivos realmente presentes na pasta `assets`. Vídeos e imagens adicionais podem ser incluídos conforme a necessidade.*

## 🚀 Como executar o projeto

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Mantenha o arquivo `index.html` junto da pasta `assets`.
4. Abra o arquivo `index.html` em um navegador.

Para disponibilizar o site na internet, publique os arquivos em uma hospedagem compatível com páginas estáticas, como o GitHub Pages.
